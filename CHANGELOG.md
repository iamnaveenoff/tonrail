# Changelog

All notable changes are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-16

First public release.

### Added
- Noise control: Off, Cancel and Aware, with five cancelling environments and three strength levels.
- 10-band equalizer with curve editing, band strip, ± fine steps, Quick tone (Bass, Voice, Treble), hold to compare, Start flat with Undo.
- Six built-in tunings with curve previews; save, rename and delete your own presets.
- Moments: one-tap combinations of noise mode, sound and gaming mode.
- Gaming mode, left/right balance, headroom protection.
- Button remapping for Multifunction ×1–×4, Volume + and Volume −.
- Device settings: rename, auto power-off, restore noise mode on reconnect, factory reset, forget paired phones.
- Connected-state panel with a headphone illustration, live battery and status.
- Splash screen, adaptive launcher icon with themed (monochrome) icon support.
- Dark, light and system appearance.
- Diagnostics log with copy.
- UI tests across themes, text sizes and connection states; protocol tests.
