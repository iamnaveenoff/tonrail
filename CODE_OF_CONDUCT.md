# Code of Conduct

This project is a place for people who like their headphones and like building things. Keep it welcoming.

## Expected

- Be kind and patient, especially with newcomers and people writing in a second language.
- Assume good intent. Ask before you judge.
- Critique ideas and code, never people.
- Accept decisions gracefully, and say so when you disagree with reasons.

## Not acceptable

- Harassment, insults, or personal attacks.
- Discriminatory language or jokes about anyone's identity, background or ability.
- Sharing someone's private information without permission.
- Sexual content or unwanted attention.
- Repeatedly derailing discussions or ignoring a maintainer's request to stop.

## Scope

This applies in issues, pull requests, discussions and anywhere you represent the project.

## Reporting

Report problems privately to the maintainer through GitHub ([@iamnaveenoff](https://github.com/iamnaveenoff)). Reports are kept confidential. Maintainers may edit or remove content, and warn, suspend or ban anyone who breaks these rules.

This code of conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
