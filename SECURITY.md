# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Use GitHub's private reporting: **Security → Report a vulnerability** on the repository page ([direct link](https://github.com/iamnaveenoff/tonrail/security/advisories/new)).

Include what you found, how to reproduce it and what an attacker could do. You'll get a reply within 7 days. Once a fix is released we'll credit you, unless you prefer to stay anonymous.

## What's in scope

- The Android app in this repository.
- How it talks to the headphones over Bluetooth LE (for example, ways another nearby device could make the app send unwanted commands).
- Data the app stores on the phone.

Weaknesses in the headphones' own firmware are out of scope; report those to the manufacturer.
